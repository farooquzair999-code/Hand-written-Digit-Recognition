# Handwritten Digit Recognition

A deep learning project that classifies handwritten digits (0–9) using a Convolutional Neural Network (CNN) built with TensorFlow and Keras.

## 📊 Results
- **Test Accuracy:** 98.58%
- **Dataset:** MNIST (60,000 training images, 10,000 test images)

## 🛠️ Technologies Used
- **Language:** Python
- **Deep Learning:** TensorFlow / Keras
- **Data & Visualization:** NumPy, Matplotlib
- **Environment:** Google Colab

## 🚀 How to Run
1. Open `Handwritten_Digit_Recognition.ipynb` in Google Colab or Jupyter Notebook.
2. Run all cells sequentially to train the model and view sample predictions.
